# Shiftly — календарь смен

Премиальный MVP на Next.js App Router + TypeScript + Tailwind CSS + Framer Motion + Zustand + date-fns + Lucide.

## Что уже есть

- левая вертикальная навигация на десктопе и отдельная мобильная навигация;
- календарь смен с типами «Смена», «Выходной», «Доп. смена», «Отпуск»;
- ручная корректировка фактических часов на любой день;
- настройки цены выхода, графика 5/2, 2/2, 1/3, 3/3, 4/2 или свободного режима;
- профиль: имя, логин, email, загрузка аватара;
- mock-вход/регистрация с сохранением состояния в localStorage через Zustand persist;
- аналитика заработка по месяцам;
- отдельная вкладка подписки;
- spring-анимации, layout transitions, bottom-sheet модалки;
- адаптивный glassmorphism-фон: на мобильном используется фото-референс с размытием, на десктопе — чистый градиент.

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`.

## Структура

```text
src/
  app/
  components/
  features/
    auth/
    calendar/
    earnings/
    settings/
    subscription/
  shared/
  store/
```

Для production-авторизации, платежей и синхронизации с БД достаточно заменить mock-логику в feature-модулях и оставить публичные типы/domain-store без изменений.

Примечание: зависимости не удалось установить в sandbox из-за ограничения времени сетевой установки, поэтому здесь лежит исходный проект и конфигурация, готовые для локального `npm install`.
